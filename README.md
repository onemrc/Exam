# 基于Web的考试报名系统

## 项目概述

这是一个基于Java EE技术栈开发的Web考试报名管理系统，主要用于管理考试报名流程，支持管理员、学生和组织部门三种角色的不同功能需求。

## 技术架构

### 开发环境
- **后端框架**: Struts2 + Hibernate + Spring
- **数据库**: MySQL 5.7
- **前端技术**: JSP + Bootstrap + jQuery
- **服务器**: Tomcat (支持)
- **Java版本**: Java 8+

### 技术栈详解
- **Struts2**: MVC框架，负责Web层控制
- **Spring**: IoC容器，管理Bean依赖注入
- **Hibernate**: ORM框架，负责数据持久化
- **MySQL**: 关系型数据库，存储系统数据
- **Bootstrap**: 前端UI框架，提供响应式界面

## 系统功能

### 用户角色
1. **管理员 (user_permit=0)**
   - 用户管理（学生、组织部门审核）
   - 考试管理（创建、发布、删除考试）
   - 考试类别管理
   - 报名信息管理
   - 公告管理

2. **学生用户 (user_permit=1)**
   - 学生注册
   - 查看可报名考试
   - 考试报名
   - 查看已报名考试
   - 查看公告信息

3. **组织部门 (user_permit=2)**
   - 部门注册
   - 查看部门相关考试信息
   - 查看公告信息

### 核心功能模块

#### 1. 用户管理模块
- 用户登录/注销
- 密码修改
- 学生注册与审核
- 组织部门注册与审核

#### 2. 考试管理模块
- 考试信息创建（考试名称、时间、地点、类别）
- 考试状态管理（未发布/已发布）
- 考试类别管理
- 考试信息查询与删除

#### 3. 报名管理模块
- 报名信息发布（报名开始/结束时间）
- 学生考试报名
- 报名状态跟踪
- 报名学生信息查询

#### 4. 公告管理模块
- 公告发布
- 公告内容管理
- 公告查询与删除

## 数据库设计

### 主要数据表
- **user**: 用户表（管理员、学生、组织部门统一管理）
- **student**: 学生信息表
- **department**: 组织部门信息表
- **exam**: 考试信息表
- **category**: 考试类别表
- **signup**: 报名信息表
- **studentsignup**: 学生报名关联表
- **examine**: 审核信息表
- **notice**: 公告信息表

### 表关系
- 用户表与学生表、部门表通过外键关联
- 考试表与类别表通过外键关联
- 报名表与考试表通过外键关联
- 学生报名表关联学生表和报名表

## 配置说明

### 数据库配置
- 数据库名: exam
- 默认用户名: root
- 默认密码: 123456
- 端口: 3306

### 部署说明
1. 导入exam.sql到MySQL数据库
2. 配置SpringConfig.xml中的数据库连接信息
3. 将项目部署到Tomcat服务器
4. 访问系统首页进行登录

## 系统特点

1. **分层架构**: 采用经典的三层架构（Action-Service-DAO）
2. **权限管理**: 基于角色的权限控制，支持三种用户类型
3. **审核机制**: 学生和部门注册需要管理员审核
4. **响应式设计**: 基于Bootstrap的响应式界面
5. **数据完整性**: 通过外键约束保证数据一致性

## 开发说明

这是一个Java EE课程设计项目，展示了如何使用经典的SSH（Struts2+Spring+Hibernate）框架构建Web应用系统。项目包含了完整的CRUD操作、用户权限管理、数据关联等企业级应用的基本功能。
